# 센터장님, 다음 주는요?

문화체육센터를 키우는 한국어 육성·경영 시뮬레이션입니다. 7년·28계절·364주 동안 대관, 클래스, 나라장터 물품 조달, 시설 입찰과 개선을 계획합니다. 우리 센터와 경쟁 센터 9곳이 함께 평가받습니다.

## 실행과 검증

Node.js 24, npm 11 이상이 필요합니다.

```sh
npm ci
npm run dev
npm test
npm run build
```

## 게임 흐름

새 게임 → 장면형 튜토리얼 → 계절 시작·이벤트 → 대관 검토 → 클래스 편성·조달 → 13주 운영 → 결산·오지선 브리핑으로 진행합니다. 2·4·6년 차와 7년 차 마지막에 종합평가를 받습니다. 평가는 명성, 재정 건전성, 주민 만족, 공공서비스를 반영합니다. 만족도의 세부 수치는 평가 전에는 공개하지 않습니다.

일반 공간은 활동 장비 3개, 대강당은 4개를 설치할 수 있습니다. 장비 보관·이전과 시설별 전용 프로그램을 지원합니다. 운영 장면은 각 활동의 스틸컷으로 표시합니다.

저장과 명예의 전당은 현재 브라우저의 로컬 저장소를 사용합니다. 다른 기기·브라우저·주소와 자동 동기화되지 않습니다. 기존 localhost 저장은 배포 주소에서 자동으로 나타나지 않습니다.

## Cloudflare Pages 배포

- 저장소: https://github.com/sirlma111216-boop/ppscon2
- 배포 브랜치: `main`
- 빌드 명령: `npm run build`
- 출력 폴더: `dist`
- 프로젝트 루트: 저장소 루트
- Node.js: `24` (`.node-version`)

Cloudflare Pages에서 이 저장소를 Git 연동하면 main에 push할 때 자동으로 빌드·배포됩니다. GitHub Actions는 별도로 타입 검사·테스트·빌드를 검증합니다. 이 README의 설정 안내 자체가 Cloudflare 연결 완료를 의미하지는 않습니다.

기존 ppscon 저장소의 서비스와 브랜치는 별도로 유지합니다. 현재 게임은 `src/center`, 그림은 `public/center`에 있습니다. 이전 게임 코드는 역사적 참고용으로 남아 있습니다. 자세한 구현·검증 결과는 `docs/center-growth/IMPLEMENTATION_STATUS.md`, 밸런스 보고서는 `reports/center-balance/BALANCE_REVIEW_20261107.html`을 참조하세요.

화폐·평가·조달 절차는 게임을 위한 모델이며 실제 나라장터와 연결되지 않습니다.
