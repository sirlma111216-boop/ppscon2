# 센터장님, 다음 주는요?

문화체육센터를 키우는 한국어 육성·경영 시뮬레이션입니다. **대관 승인 → 남은 시간의 클래스 편성 → 13주 운영·결산**을 반복하며 **6년·24턴·312주**를 운영합니다. 우리 센터와 경쟁센터 9곳, 총 10개 기관이 같은 운영 규칙으로 성장합니다.

## 실행

Windows에서는 `start-game.cmd`를 더블 클릭합니다. Node.js 24와 npm 11 이상을 사용하며, 의존성이 없으면 실행 파일이 먼저 설치합니다.

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5174 --open
npm run check
npm test
npm run build
```

자동 저장은 브라우저의 현재 주소·포트별로 구분됩니다. 개발 서버가 다른 포트를 선택하면 기존 저장이 보이지 않을 수 있습니다. 도움말에서 새 게임을 시작할 수 있습니다.

## 플레이 흐름

1. 센터 **외관 그림의 방 이름**을 눌러 내부로 들어갑니다. 처음에는 소강당 1·생활체육실·공예실·배움실 4곳이 열려 있습니다.
2. 대관 신청을 승인하거나 거절합니다. 이미 클래스가 있는 시간은 취소 여부를 확인한 뒤 대관으로 바꿉니다. 확인 전에는 기존 클래스가 유지됩니다.
3. **대관 확정 · 클래스 편성**으로 넘어가 남은 시간에 클래스를 놓습니다. 승인된 대관을 취소해 클래스 시간을 확보하거나 빈칸으로 둘 수도 있습니다.
4. 잠긴 클래스는 클릭해 필요한 물품을 확인합니다. 나라장터 조달 화면에서 **해당 방에** 물품을 주문하고 설치를 마쳐야 열립니다.
5. 계절을 실행하면 13주 전체를 한 번 계산합니다. 화면에는 **13주차·마지막 주 결과**의 5개 시간대를 요약해서 보여줍니다. 장면 재생이나 건너뛰기는 돈·공사 진행을 추가로 바꾸지 않습니다.
6. 다음 계절의 계획을 바꾸고 2·4·6년 차 겨울에 종합평가를 받습니다.

## 일곱 공간과 조달

| 공간 | 면적·정원 | 운영 가능한 클래스 |
|---|---|---|
| A 소강당 1 | 80㎡·32명 | 모든 클래스 · 다목적 |
| B 생활체육실 | 120㎡·24명 | 요가·스트레칭·댄스·주민 모임 |
| C 대강당 | 300㎡·120명 | 요가·스트레칭·댄스·주민 모임 |
| D 소강당 2 | 90㎡·40명 | 모든 클래스 · 다목적 |
| E 공예실 | 45㎡·16명 | 공예·주민 공예·주민 모임 |
| F 배움실 | 50㎡·18명 | 공예·주민 공예·디지털·주민 모임 |
| G 프리미엄회의실 | 40㎡·12명 | 디지털·주민 모임 |

방의 용도, 면적, 장비 자리는 각각 제한입니다. 공예는 공예 세트·30㎡, 요가/스트레칭은 매트·60㎡, 댄스는 매트+음향·80㎡, 디지털은 컴퓨터+영상 장비·40㎡가 필요합니다. 주민 모임은 별도 설비가 필요 없습니다. **다른 방의 장비는 공유하지 않습니다.** 설치를 기다리는 클래스는 잠금 상태로 표시하고, 해당 방의 용도와 맞지 않는 클래스는 목록에서 제외합니다.

조달 카탈로그 각 물품에 연결 클래스·추가 설비를 표시합니다. 물품을 들일 수 없는 방에는 설치 불가를 표시합니다. 설치가 끝난 장비는 적합한 다른 방으로 8점에 이전할 수 있으며 재설치 전에는 사용할 수 없습니다.

C·D·G는 **시설 공고 → 업체 3곳 비교 → 계약 → 9/18/31주 공사 → 개방**으로 확장합니다. 공사비·완성도·관리비가 다르고 공사 중에도 안전관리비가 듭니다. 정원·쉼터 조성 이후에는 외관·광장 개선을 할 수 있습니다. 이 고액 환경 개선 사업은 실제 외관 그림, 명성, 이용 경험, 대관 견적에 반영됩니다.

## 지원예산과 평가

초기 현금 1,080점 중 기본운영비 320점을 유보해 가용예산은 760점입니다. 이후 매년 기본 지원예산은 900점이며, 2·4년 차 평가 결과에 따라 다음 2개 연도의 지원액이 달라집니다.

| 종합평가 항목 | 비중 |
|---|---:|
| 명성 | 25% |
| 재정 건전성 | 20% |
| 주민 만족 | 30% |
| 공공서비스 | 25% |

1·2·3위는 대통령상·국무총리상·장관상과 지원예산 +6·4·2%를 받습니다. 하위 3곳은 −2·4·6%입니다. 기본 900점에 매번 적용하며 이전 인상률과 누적하지 않습니다. 6년 차에는 다음 연도가 없어 새 지원금을 지급하지 않습니다.

**6년 차 평가상**은 최근 2년의 성적입니다. **6년 종합 최종상**은 종합평가 평균 50% + 마지막 평가 50%로 결정합니다. 최종 비교표와 엔딩은 같은 순위·동점 처리 함수를 사용합니다. 모든 예산·기관·포상은 게임용 창작 설정입니다.

## 구현과 남은 작업

현재 7개 공간, 10종 활동, 12종 물품안, 방별 설치·이전·마모, 시설/환경 개선 사업, 9개 경쟁기관, 6년 평가와 저장 복원을 구현했습니다. 외관 3단계·실내 7장·클래스 카드 7장·경쟁센터 외관 9장을 사용합니다. 대화 초상과 클래스 그림의 사람은 정적이며 본게임 센터 장면에는 사람 애니메이션이 없습니다.

**도예 수업은 별도 미리보기이며 본게임에 적용하지 않았습니다.** `/center/prototypes/pottery/`는 작업 중인 시안입니다. 랜덤 이벤트·계절 중 선택 분기·캐릭터 관계 시스템·혁신제품 시범사용은 미구현입니다. 음향은 Web Audio 합성 스케치이며 최종 음원과 외부 플레이테스트, 장기 밸런스 조정이 남아 있습니다.
