# 센터장님, 다음 주는요?

문화체육센터를 키우는 한국어 육성·경영 시뮬레이션입니다. **대관 승인 → 남은 시간의 클래스 편성 → 13주 운영·결산**을 반복하며 **6년·24턴·312주**를 운영합니다. 우리 센터와 경쟁센터 9곳, 총 10개 기관이 같은 운영 규칙으로 성장합니다.

## 실행

Windows에서는 `start-game.cmd`를 더블 클릭합니다. Node.js 24와 npm 11 이상을 사용하며, 의존성이 없으면 실행 파일이 먼저 설치합니다.

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5174 --open
npm run check
npm test
npm run build
```

자동 저장은 브라우저의 현재 주소·포트별로 구분됩니다. 개발 서버가 다른 포트를 선택하면 기존 저장이 보이지 않을 수 있습니다. 도움말에서 새 게임을 시작할 수 있습니다.

## 플레이 흐름

1. 센터 **외관 그림의 방 이름**을 눌러 내부로 들어갑니다. 실내에서는 7개 방으로 바로 이동할 수 있습니다. 처음에는 소강당 1·생활체육실·공예실·배움실 4곳이 열려 있습니다.
2. 대관 신청을 승인하거나 거절합니다. 이미 클래스가 있는 시간은 취소 여부를 확인한 뒤 대관으로 바꿉니다. 확인 전에는 기존 클래스가 유지됩니다.
3. **대관 확정 · 클래스 편성**으로 넘어가 남은 시간에 클래스를 놓습니다. 클래스→시간 또는 시간→클래스 중 편한 순서로 고릅니다. 승인된 대관을 취소해 클래스 시간을 확보하거나 빈칸으로 둘 수도 있습니다.
4. 잠긴 클래스는 클릭해 필요한 물품을 확인합니다. 나라장터 조달 화면에서 **해당 방에** 물품을 주문하고 설치를 마쳐야 열립니다.
5. 계절을 실행하면 13주 전체를 한 번 계산합니다. 화면에는 **13주차·마지막 주 결과**의 5개 시간대를 요약해서 보여줍니다. 장면 재생이나 건너뛰기는 돈·공사 진행을 추가로 바꾸지 않습니다.
6. 다음 계절의 계획을 바꾸고 2·4·6년 차 겨울에 종합평가를 받습니다.

구매·대관·편성·시설 계약을 처리하면 화면에 결과 알림을 표시합니다. 성공 알림은 잠시 뒤 사라지고 오류는 닫거나 다음 알림으로 바뀔 때까지 남습니다. 시설 계약 알림에는 실제 지출과 예상 완공 시점이 함께 나옵니다.

외관 아래에는 일곱 방 전체의 주간 현황을 표시합니다. 대관 검토에서는 방 그림 아래 현황·오른쪽 신청 목록, 클래스 편성에서는 왼쪽 그림과 시간표·오른쪽 클래스 카드의 55:45 두 열로 구성하며 좁은 화면에서는 순서대로 이어집니다. 카드 영역이 넓으면 세 장씩, 좁으면 두 장씩 배치합니다. 대관·클래스·빈 시간·미개방을 구분하고, 하단 버튼으로 기존 편성을 유지한 채 대관 검토로 돌아갑니다. 빈 시간이 있는 상태로 계절을 시작하면 개수와 해당 방을 확인한 뒤 그대로 운영할 수 있습니다.

## 일곱 공간과 조달

| 공간 | 면적·정원 | 운영 가능한 클래스 |
|---|---|---|
| A 소강당 1 | 80㎡·32명 | 일반 클래스 7종 · 다목적 |
| B 생활체육실 | 120㎡·24명 | 일반 운동·생활안전 + **전용 필라테스·실내 사이클** |
| C 대강당 | 300㎡·120명 | 일반 운동·생활안전 + **전용 뮤지컬·오케스트라·무대기술** |
| D 소강당 2 | 90㎡·40명 | 일반 클래스 7종 · 다목적 |
| E 공예실 | 45㎡·16명 | 공예·주민 공예·생활안전 + **전용 전문 도예·목공** |
| F 배움실 | 50㎡·18명 | 공예·주민 공예·디지털·생활안전 + **전용 영상 제작** |
| G 프리미엄회의실 | 40㎡·12명 | 디지털·생활안전 + **전용 스피치·외국어 토론·창업 피칭** |

방의 용도, 면적, 장비 자리는 각각 제한입니다. 공예는 공예 세트·30㎡, 요가/스트레칭은 매트·60㎡, 댄스는 매트+음향·80㎡, 디지털은 컴퓨터+영상 장비·40㎡가 필요합니다. **생활안전 교실(P06)**은 추가 설비 없이 여는 무료 주민 클래스이며 운영비가 듭니다. **모임 대관(P05)**은 외부 단체에 공간을 빌려주는 별도 활동으로 유지합니다. **다른 방의 장비는 공유하지 않습니다.** 설치를 기다리는 클래스는 잠금 상태로 표시하고, 해당 방의 용도와 맞지 않는 클래스는 목록에서 제외합니다.

조달 카탈로그 각 물품에 연결 클래스·추가 설비를 표시합니다. 물품을 들일 수 없는 방에는 설치 불가를 표시합니다. 설치가 끝난 장비는 적합한 다른 방으로 8점에 이전할 수 있으며 재설치 전에는 사용할 수 없습니다.

활동 장비는 일반 방 2자리·대강당 3자리이며 설치 대기도 자리를 차지합니다. 이동식 가구·공간 분리 보조 장비와 센터 공용 설비는 별도로 셉니다. 자리가 가득 차면 설치 품목과 장비 관리 바로가기를 표시합니다. 장비는 8점에 보관하고 8점에 다시 설치할 수 있습니다. 보관 중에도 유지비는 계속 들며 재설치는 준비 시간을 사용합니다. 필요한 장비를 빼는 클래스는 확인 후 비우고, 승인 대관은 먼저 별도로 취소해야 합니다. 매각은 지원하지 않습니다.

C·D·G는 **시설 공고 → 업체 3곳 비교 → 계약 → 9/18/31주 공사 → 개방**으로 확장합니다. 한 계절은 13주이므로 **1/2/3턴**이 걸리며 제안서와 진행 화면에 예상 완공 계절·주차를 표시합니다. 공사비·완성도·관리비가 다르고 공사 중에도 안전관리비가 듭니다.

**조경과 쉼터·건물 외관·다목적 광장**은 순서 없이 선택하는 세 독립 환경 사업입니다. 기본 사업 규모는 각각 2,400·4,000·2,000점이며, 동시에 계약해도 따로 진행합니다. 완료 조합에 따라 **8가지 외관**과 명성·이용 경험·대관 견적이 바뀝니다. 옛 외관·광장 복합 계약은 가격·관리비·공사 진행·효과를 보존하며 광장에 중복 투자할 수 없게 처리합니다.

## 지원예산과 평가

초기 현금 1,080점 중 기본운영비 320점을 유보해 가용예산은 760점입니다. 이후 매년 기본 지원예산은 900점이며, 2·4년 차 평가 결과에 따라 다음 2개 연도의 지원액이 달라집니다.

| 종합평가 항목 | 비중 |
|---|---:|
| 명성 | 25% |
| 재정 건전성 | 20% |
| 주민 만족 | 30% |
| 공공서비스 | 25% |

1·2·3위는 대통령상·국무총리상·장관상과 지원예산 +6·4·2%를 받습니다. 하위 3곳은 −2·4·6%입니다. 기본 900점에 매번 적용하며 이전 인상률과 누적하지 않습니다. 6년 차에는 다음 연도가 없어 새 지원금을 지급하지 않습니다.

**6년 차 평가상**은 최근 2년의 성적입니다. **6년 종합 최종상**은 종합평가 평균 50% + 마지막 평가 50%로 결정합니다. 최종 비교표와 엔딩은 같은 순위·동점 처리 함수를 사용합니다. 모든 예산·기관·포상은 게임용 창작 설정입니다.

## 구현과 남은 작업

현재 7개 공간, 21종 활동(클래스 18·대관 3), 23종 물품안, 방별 설치·이전·보관·마모, 시설/환경 개선 사업, 9개 경쟁기관, 6년 평가와 저장 복원을 구현했습니다. 외관 8조합·실내 7장·클래스 카드 18장·경쟁센터 외관 9장을 사용합니다. 공간 7개와 환경 개선·센터 외관 버튼은 **한글까지 포함한 무광 은색 이미지 9장**입니다. 전용 클래스 11종은 각 지정 방에서만 열며 종류별 센터 전체 주 2칸 한도와 별도 수요를 사용합니다. 기구 필라테스는 수익, 전문 도예는 명성, 영상 제작은 균형에 특화했습니다. 일반 수업은 유지하고 다목적실에서 전용 수업을 열 수는 없습니다.

외관 8장의 배포 파일 합계는 약 **3.12MB**이며, 외관 표시에는 현재 조합 한 장(약 **0.36~0.44MB**)을 선택합니다. 이 수치는 전체 앱이나 다른 화면의 추가 이미지 전송량을 뜻하지 않습니다.

실제 운영한 **공예·주민 공예·전문 도예는 방 그림 자리에서 테두리 없는 장면**으로 표시합니다. 건물·가구·환경은 고정하고 네 인물의 고개·상체·팔이 함께 작게 움직입니다. 자동 시간대 재생이 끝나도 마지막 실제 공예 기록을 계속 보여 주며 사용자가 **계절 결과 보기**를 눌러야 결산창이 열립니다. 결과 시간표를 눌러 다른 실제 기록을 볼 수 있고, 빈 시간·계획·외관은 정적입니다. 별도 수업 팝업이나 계획 미리보기는 없습니다. 장면·일시 정지·방 이동은 수입과 공사를 다시 계산하지 않습니다. 다른 클래스의 애니메이션은 아직 연결하지 않았습니다.

랜덤 이벤트·계절 중 선택 분기·캐릭터 관계 시스템·혁신제품 시범사용은 미구현입니다. 음향은 Web Audio 합성 스케치이며 최종 음원과 외부 플레이테스트, 장기 밸런스 조정이 남아 있습니다.
