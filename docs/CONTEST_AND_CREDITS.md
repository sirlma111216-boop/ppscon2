## 표현 검수

- 요구기관, 조달지원, 공급자, 이용자의 역할을 분리한다.
- 실제 필요에 맞는 기능이 먼저이며, 필수 조건 안에서 예산·일정을 비교한다.
- 같은 요구를 같은 기준으로 비교한 이유를 보인다. 프로그램이 법적 공정성을 인증한다는 표현은 하지 않는다.
- 혁신제품의 첫 공공구매·시범사용·피드백·개선 가능성을 경험으로 표현한다. 생성한 가상 제품을 실제 지정 제품이라고 하지 않는다.
- 안전을 포기하거나 시민의 가치를 서열화해 점수를 얻는 선택을 만들지 않는다.
- 모든 가격·시간·제품은 가상 게임 데이터. 실제 입찰/계약/검사 전 절차의 정확한 재현이 아니다.

## 권리와 원본 보관

모집요강은 출품자 저작권, 수상작의3년 비독점 공익 이용과 별도 협의가 필요한 변경, 필요 시 원본 제출을 다룬다. 제출 전 원문 전체를 다시 확인한다. 제3자 자산은 AI 포함 상업적 이용 가능 조건과 주최 측 이용 범위를 확인한다. 수상 이력이 있는 작품이나 타 기관에 같은 작품을 제출하는 제한도 원문에 따라 확인한다.

이 저장소 자체에 포괄적인 MIT/CC0 라이선스를 임의로 부여하지 않는다. 코드·생성물·참고문서의 권리는 구분한다. 특정 유료 글꼴, 공식 로고, 실존 캐릭터, 유명 아티스트 스타일을 무단 포함하지 않는다.

### 이번 인계 자료에서 실제 수행한 AI 사용

| 대상 | 실제 상태 | 도구와 사람의 기여 |
|---|---|---|
| 기획·개발 지침 | 작성 | AI가 초안·정책 정합성·수치 검토, 제작자가 방향·1인 제작·스타일 요구 제시 |
| 이미지 PNG | 생성 및 선별 | OpenAI imagegen 내장 도구. 한국 동네 리소그래프 종이 무대 방향, 프롬프트·참조·수정 기록 별도 보관 |
| 음악·효과음·환경음 | 프롬프트만 작성 | ElevenLabs용 제작 명세. 실제 음원 생성·청음·편집은 미수행 |
| 게임 코드 | 구현(2026-11-05) | Claude Code(모델 Claude Fable 5.1)가 이 저장소의 지침·명세·에셋을 읽고 게임 코드·테스트·점검 스크립트를 작성. 제작자가 방향과 자료를 제시하고 ‘음원은 나중에 제공’으로 범위를 정함 |
| 게임용 이미지 파생본 | 생성(2026-11-05) | 위 원본 PNG를 `scripts/build-assets.mjs`(sharp 0.35.5)로 WebP 변환·자르기·낮은 알파 정리. 새 그림을 생성하지 않음. 대응표: `IMAGE_DERIVATIVES.md` |
| 범용 조각 그림(SVG) | 작성(2026-11-05) | 전용 그림이 없는 부적격 제시안 6종과 학습 재료·해·파비콘을 Claude Code가 코드(SVG 도형)로 그림. 이미지 생성 모델은 쓰지 않음. 위치: `src/components/GenericProp.tsx`, `public/favicon.svg` |

Google Imagen을 사용했다고 표기하지 않는다. 실제 이미지 도구는 이 세션의 OpenAI imagegen이며 정확한 내부 모델 버전은 도구가 노출하지 않아 임의로 적지 않는다.

이미지 파일의 ID·해상도·해시·생성 프롬프트는 `public/assets/images/manifest.json`과 `IMAGE_PROMPTS.json`에서 확인한다. 초기 미채택 시도는 최종 배포 에셋으로 간주하지 않는다.

### 스타일 참고

사용자가 제공한 `DESIGN-zapier.md` 원본을 `references/`에 보관했다. 선택 목록: https://getdesign.md/zapier/design-md . 공개 컬렉션: https://github.com/VoltAgent/awesome-design-md . 이 컬렉션의 MIT 고지는 `references/awesome-design-md-LICENSE.txt`에 보관한다. 브랜드명·로고·유료 글꼴에 대한 권리를 부여하는 것으로 해석하지 않는다. 원본을 게임에 맞게 수정한 내용은 루트 `DESIGN.md`에 명시했다.

```text

실제 생성·제작 도구와 버전: Claude Code, 모델 Claude Fable 5.1 (claude-fable-5-1)

프롬프트/참조 원본: PROMPT_CLAUDE_CODE.md, CLAUDE.md, DESIGN.md, docs/GAME_SPEC.md, docs/IMAGE_ASSETS.md, 두 매니페스트
사람이 수정·선별한 내용: (제작자가 플레이해 보고 고친 내용을 여기에 적는다. 2026-11-05 현재 없음)
생성 당시 사용 요금제와 권리 확인 자료: (제작자가 확인해 적는다)
게임 / 시연 영상 / 주최 측 홍보 재사용 범위: (제작자가 확인해 적는다)
최종 파일 해시와 원본 위치: 저장소 커밋으로 관리(게임 구현 커밋 9b6f597, 2026-11-05)
```

토큰·비밀번호·개인정보·서명한 신청서는 이 기록에 포함하지 않는다. 음원은 `AUDIO_ELEVENLABS.md`의 매체별 권리 확인을 완료한 뒤 사용한다.

## 약1분 시연 영상 기획

| 초 | 실제 게임 화면 | 전달할 내용 |
|---|---|---|
| 0~8 | 인트로, 펼쳐지는 동네 | 상자와 시민의 하루 |
| 8~18 | 도서관 수요·필수조건 | 필요에 맞는 구매 |
| 18~32 | 같은 기준의 대안 비교, 일정 갈등 수정 | 판단과 게임성 |
| 32~43 | 공급·설치, 독서 공간 전환 | 선택의 실제 변화 |
| 43~55 | 혁신 안내 도구 관찰→개선→재확인 | 첫 구매와 피드백 |
| 55~60 | 살아난 동네, 게임 제목 | 기억에 남는 마무리 |

현재는 촬영 기획이며 MP4가 제작됐다는 뜻이 아니다. 최종 영상에는 실제 구현 화면만 사용한다.
