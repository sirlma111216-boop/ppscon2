## 장면에서 글을 얹는 위치

아래 숫자는 원본 전체에 대한 권장 `[왼쪽, 위, 너비, 높이]` 비율이다. 제시한 영역 안에 제목과 짧은 조작부를 실제 HTML로 배치한다. 긴 결과 목록과 큰 글씨는 그림 아래 일반 문서 흐름으로 이어서 읽게 하고, 모바일에서는 영역을 벗어나기 전에 패널을 아래로 옮긴다.

| 엔딩 | 왼쪽 위 짙은 하늘 `[0.045, 0.07, 0.285, 0.25]` | 밝은 제목·짧은 요약. 선택별 결과는 게임 상태에서 생성 |

## 지도에 건물을 놓는 방법

지도를 원본 3:2 비율로 표시한다. 다음 값은 실제 빈 필지를 보고 정한 첫 배치값이다. `boardAnchorNormalized`는 지도에서 건물이 접지할 지점, `spriteAnchorNormalized`는 투명 여백을 포함한 건물 원본에서 그 지점에 맞출 좌표다. 둘 모두 왼쪽 위가 (0, 0)이다. 건물의 표시 너비는 지도 표시 너비에 마지막 열의 값을 곱한다. 세로는 원본 비율을 따른다.

| 시설 | 필지 | 지도 접지점 (x, y) | 건물 원본 접지점 (x, y) | 너비 비율 |
|---|---|---|---|---:|
| 도서관 | 왼쪽 위 | (0.25, 0.36) | (0.50, 0.865) | 0.32 |
| 학교 | 오른쪽 위 | (0.75, 0.42) | (0.50, 0.92) | 0.33 |
| 주민센터 | 왼쪽 아래 | (0.235, 0.755) | (0.50, 0.915) | 0.32 |
| 공원 | 오른쪽 아래 | (0.75, 0.825) | (0.50, 0.95) | 0.34 |

건물의 왼쪽 좌표는 `지도너비 × boardX − 건물표시너비 × spriteX`, 위쪽은 `지도높이 × boardY − 건물표시높이 × spriteY`이다. 지도와 조작 버튼은 같은 좌표계를 쓴다. DOM에 시설 이름을 붙이고, 그림이 작아진 경우 선택 영역은 최소 48×48 CSS 픽셀을 확보한다. 임무 3은 기존 퍼걸러 옆의 행사 공간에 이동 그늘막을 추가해 구매 전후가 구별되게 한다.

## 아틀라스 15개를 그리는 방법

매니페스트에서 두 `kind === "atlas"` 항목만 `sprites`를 갖는다. `cropRect`와 `subjectRect`의 단위는 원본 픽셀, 순서는 `[x, y, 너비, 높이]`이며 오른쪽과 아래의 끝 좌표는 포함하지 않는다. Canvas라면 `drawImage(sheet, x, y, w, h, dx, dy, w * scale, h * scale)`처럼 같은 비율로 그린다. 카드를 채우거나 발밑을 정렬할 때는 `subjectRect`의 중심과 하단을 사용한다. 이 값은 시트 기준이므로 잘라낸 그림 안의 좌표를 구할 때는 `cropRect`의 x, y를 뺀다.

| ID | 사용처 | 선택에 따라 보일 변화 |
|---|---|---|
| `foldTable` | 임무 1 · L1 | 접이식 테이블을 수납 위치로 옮겨 오후 활동 공간을 확보 |
| `mobileTable` | 임무 1 · L2 | 바퀴 달린 모듈을 모아 프로그램 배치로 전환 |
| `compactDesk` | 임무 1 · S1, 임무 3 · E1 | 소형 수동 책상의 높이 조절과 여유 있는 좌석 간격 |
| `wideDesk` | 임무 1 · S2, 임무 3 · E2 | 넓은 상판에 학습 재료를 전개 |
| `kiosk` | 임무 2 · I1, I2 | 공통 외형. I1의 긴 안내 문구와 I2의 복잡한 메뉴는 DOM 미리보기에서 개별 개선 |
| `portableSign` | 임무 2 · G1, G2 | G1은 일찍 도착해 조립하고, G2는 늦게 도착해 완성형으로 배치 |
| `bench` | 임무 2·3 공원 | 길찾기·휴식 장면의 기존 좌석. 그늘막 그림에는 좌석이 포함되어 중복 배치에 주의 |
| `solarLamp` | 임무 3 이후 공원 | 저녁의 기존 환경 소품. 구매 물품 수와 예산은 [임무 데이터](GAME_SPEC.md)에 따름 |
| `deliveryVan` | 임무 1·2·3 | 계획한 납품·설치 순서에 맞춰 물품이 도착 |

| `wheelchairUser` | 임무 1·2·3 | 책상 주변의 이용 공간, 길찾기, 공원 행사 참여 |
| `staff` | 임무 1·2·3 | 현장 확인, 임무 2의 이용 관찰·재확인 |
| `supplier` | 임무 1·2·3 | 물품 전달, 임무 2의 피드백 반영 |

임무 3의 P1·P2는 별도 원본 `shade-canopy.png`를 공유한다. P1은 현장 조립 두 칸, P2는 사전 조립 후 배치 한 칸의 차이를 일정과 조립 연출에 반영한다. P1·P2 비교와 검수에서는 실제 그늘·이동성 요구를 설명한다.

전용 그림이 없는 제시안도 비교·미리보기·잠정 선택을 제공한다. L0는 고정형 큰 테이블로 남을 바닥 면적, S0·E0는 고정 높이, I0는 음성 전용 안내, G0는 이동 불가, P0는 그늘 없는 장식물을 범용 아이콘과 DOM 상황 설명으로 보여준다. 적격안과 같은 카드 서식을 적용하고 선택 후 필수 조건의 충족 여부와 확정 가능 여부를 문장으로 알려준다.

### 원본 검산

- PNG의 실제 크기·색상 모드·알파 채널을 읽고 원본 바이트로 SHA-256을 계산했다. 원본을 자른 파일은 생성하지 않았다.
- 품목 시트는 x=424·818, y=412·812에서 셀을 나눴다. 3등분의 마지막 행은 y=836부터지만 태양광 등의 상단은 알파 2 기준 y=835부터 보인다. 현재 좌표는 패널과 가장자리까지 포함한다.
- 주민 시트는 x=570·970, y=512의 투명 통로를 기준으로 나눴다. 각 셀에서 알파가 1 이상인 픽셀 전체를 감싸는 `cropRect`를 기록했다. 희미한 인쇄 자국까지 담기므로 여백이 서로 다르다. `subjectRect`는 위치 정렬을 위해 알파 2 이상인 범위만 측정한 값이다.
- 양쪽 시트 모두 15개 사각형을 각각 원본 좌표 배열에 대입했다. 시트별로 사각형 간 겹침 0픽셀, 누락된 알파 1 이상 픽셀 0개를 확인했다. 수치 원문은 각 아틀라스의 `cropCheck`에 있다.
