# 실별 전용 클래스와 장비 보관

2026-11-06. 기존 일반 수업 7종·평가 가중치·예산·장비 자리 한도를 유지하면서 추가한 전용 수업 11종의 엔진 규칙이다. 화면과 그림은 별도 통합 검증 대상이다. 아래 마지막의 72게임 비교는 전용 11종 확정 전 이력으로 구분한다.

전용 수업 수는 B 2종·C 3종·E 2종·F 1종·G 3종이다. 일반 수업까지 합한 실제 선택지 수는 A 7종·B 6종·C 7종·D 7종·E 5종·F 5종·G 5종이다. `Program.exclusiveRoom`이 수업 장소, `Offer.exclusiveRoom`이 전용 장비의 새 구매·이전·재설치 장소를 결정한다. A/D의 다목적 용도로 전용 수업을 대신할 수 없다.

매출은 만석일 때의 기준이다. 실제 참여 인원·가격 정책에 따라 달라지고 정비·고정비·장비 유지비가 추가된다. 명성은 실제 참여 인원과 이용 만족도에 계수를 적용하며 기존 계절 성장 상한을 유지한다. 명성·숙련 레벨로 강제 잠그지 않는다.

- 전용 11종 모두 **각 클래스별 센터 전체 주 2회**까지다. `Program.weeklyLimit`과 `getProgramPlacementError`로 편성을 제한하고, 운영 계산에서도 상한을 재검사한다.
- 각각 시간대가 다른 신청 집단 두 개를 추가했다. 신청 집단은 한 주에 한 번만 참여하며 방을 늘려도 수요가 복제되지 않는다.
- 추가 집단은 유료 민간 수요로 분류한다. 공공서비스 분모를 늘리지 않고, 고급 수업만으로 공공서비스 실적을 만들지 않는다.
- 가격의 상한을 가진 신청 집단이므로 요금을 올려도 모든 집단이 남는 것은 아니다.
- 해당 방의 모든 장비가 설치 완료·상태 20 이상이어야 열린다. 다른 방이나 창고의 장비를 빌려 쓰지 않는다.
- 뮤지컬과 오케스트라는 준비 인력 2명이 필요하며 다른 전용 수업은 1명이다. 대강당은 세 자리이므로 무대+음향+조명을 설치해 두 종류를 준비하거나 악기 세트로 구성을 바꾸는 선택이 생긴다.

## 보관·재설치·이전

- 설치 완료된 방별 장비만 보관한다. 설치 중 장비와 센터 공용 설비는 보관할 수 없다.
- 보관 8점, 재설치 8점이다. 기존 직접 이전도 8점이다. 원래 개체 ID와 상태를 유지하고, 보관 중에도 유지비·유보금 의무는 유지한다.
- 보관하면 방의 활동/보조 자리에서 빠지고 해당 방의 기능을 제공하지 않는다. `stored: true, room: null, ready: false`로 기록한다. 같은 `room: null`인 공용 설비와 `stored` 값으로 구분한다.
- 재설치는 열린 방의 용도·장비 자리·같은 물품군 중복을 검사하고 기존 물품의 설치 작업 수만큼 기다린다. 재설치만으로 마모가 회복되지 않는다.
- 해당 장비가 필요한 클래스가 있으면 기본 요청은 실패한다. 영향받는 시간과 클래스를 확인한 뒤 `allowClearPlan: true`를 명시해야 그 클래스만 비운다. 다른 방과 무관한 클래스는 보존한다.
- 승인한 대관에 필요한 장비는 보관/이전할 수 없다. 대관 화면에서 먼저 해당 승인을 취소해야 한다. 클래스 확인 옵션으로 대관을 자동 취소하지 않는다.
- 창고에서 다른 방으로 재설치할 수 있다. 철거·매각·자동 일괄 교체는 구현하지 않았다.

## 공개 함수와 저장 호환

```ts
getStorageImpact(institution, instanceId)
// { room, programs, slots, rentalIds }
storeEquipment(state, instanceId, { allowClearPlan?: boolean })
moveEquipment(state, instanceId, targetRoom, { allowClearPlan?: boolean })
reinstallEquipment(state, instanceId, targetRoom)
// 위 세 변경 함수는 { state, error? } 반환. 실패하면 원본 state 반환.
getProgramWeeklyCount(institution, programId)
getProgramPlacementError(institution, room, slot, programId)
```

기존 저장에는 `stored` 필드가 없어도 정상이다. 저장 버전과 키는 변경하지 않으며 기록·현금·이전 물품을 재계산하지 않는다. 보관 중인 장비가 방을 점유하거나 설치 완료라고 주장하는 저장, 공용 설비의 보관, 보관 장비를 가리키는 설치 작업, 주 2회를 초과한 고급 편성은 거절한다.

전용실 규칙은 별도 `specialtyRulesVersion:1`로 한 번만 이관한다. 이 값이 없는 옛 저장의 부적합 P11/P12/P13 편성은 해당 칸만 비운다. 용도가 바뀐 전용 장비는 새 비용 없이 개별 보관하고 그 장비의 설치 작업만 취소한다. 개체 ID·마모·소유 수·현금·유보금·유지비·이전 운영 보고서·평가·시설 공사는 보존한다. 단 E13의 screen이 일반 P07 또는 승인 P10에 필요하면 장비를 원래 방에 남겨 해당 수업·계약을 유지한다. `migrationNotices`에 변경별 안내를 기록하며 UI는 이관 전 원문 백업과 확인 안내를 연결해야 한다. 새 revision 저장의 잘못된 방 전용 편성은 오류로 거절한다.

탄탄·배움·새봄센터는 2년부터 자금 여력이 생기면 각각 B 필라테스·E 도예·F 영상 제작으로 투자한다. 리듬·별빛·늘품은 시설 개방 후 C 뮤지컬·C 무대기술·G 외국어 토론을 준비한다. 플레이어와 같은 구매/보관 비용·설치 대기·유지비·편성 상한을 사용한다. 기존 물품의 상위 기능을 새 물품이 제공하면 하위 세트를 중복 구입하지 않는다.

## 전용 11종 확정 후 독립 검증

동결 엔진에서 기존 6전략 × 12시드와 11전용 수업 × 3시드를 다시 실행했다. 합계 **105회 실행·2,520계절·415,141개 불변식 검사 실패 0건**이다. 같은 정책·시드 9회가 두 묶음에 겹치므로 서로 다른 조합은 96개이며 별도 holdout은 아니다.

11종 모두 실제 참석자가 있는 주 2회 운영에 도달했다. C/G는 무료 개방하지 않고 공고·유료 계약·18주 공사·장비 조달/설치를 거쳐 4~5턴에 첫 수업을 열었다. 일반 공공 혼합과 고급 공공 혼합은 12게임 모두 상위 3위였고, 전용 수업 주력+대관은 공공서비스가 0이어서 모두 10위였다. 이 검사는 시설 확장·환경 투자·전용 11종의 혼합 최적화나 사람이 느끼는 재미를 증명하지 않는다.

새 제한 직전 실제 API로 만든 P11/A·P12/A·P13/G 저장 3개도 이관했다. 자금·유보·진행·완료 기록·평가·시설·장비 개체·상태 보존, 입력 불변, 이관 멱등성을 확인했다. 세부 점수·현금·경고·실제 공사 경로와 재현 스크립트는 [방 전용 수업 11종 검증](../../reports/center-balance/EXCLUSIVE_CLASSES_REVIEW.md)에 기록했다.

## 전용 11종 확정 전의 12시드 장기 비교 — 이전 개정 이력

아래는 P11/P12/P13이 여러 방에서 가능했던 앞선 개정의 기록이며, 새 전용 11종 및 C/G 투자 이후의 최종 수치로 인용하지 않는다. 당시 보고서는 [고급 클래스 비교](../../reports/center-balance/ADVANCED_CLASSES_REVIEW.md)를 따른다.

공개 엔진 API만으로 6전략 × 12시드, 72게임·1,728계절을 운영했다. 시작 현금·지원금을 동일하게 두고 정상 구매·설치·정비 절차를 사용했다. 수요 중복, 고급 주간 한도, 유보금, 지원금, 저장 유효성 등 115,992개 불변식 검사에서 실패는 0건이었다.

고급 혼합과 일반 혼합은 각각 12게임 모두 상위 3위였다. 고급 주력 봇의 첫 운영은 3~4턴, 공공 수업과 투자를 병행하는 혼합 봇은 6~9턴이었다. 이번 실험에서는 고급 수업만 늘려 공공서비스를 생략하는 방식이 수상하지 못했고 일반 수업 중심으로도 상위 3위에 도달했다.

이 비교는 사람이 느끼는 재미나 최적 전략의 증명이 아니다. 봇은 공개 수요를 탐욕적으로 편성하고 초기 4개 방을 유지하며 시설/환경 사업·직원 교육을 하지 않는다. 구매 후 150점 여유를 남기며 예측 경고를 자동 복구하지 않는다. 일반 혼합에서는 평균 2계절 운영비 경고가 있었고, 나머지 전략에서는 없었다. 모든 고급 주력 전략도 남은 시간에는 수익성 있는 대관을 승인한다.

필라테스의 ‘수익’은 수업 자체의 만석 주당 순이익이 가장 크다는 의미다. 6년 말 현금은 명성으로 대관이 빨리 성장하는 도예가 더 많았으며, 필라테스의 빠른 현금흐름을 시설 확장에 재투자하는 효과는 이 실험에 포함되지 않았다. 따라서 마지막 현금의 우위를 보장하는 설명은 하지 않는다.

첫 비교를 실행한 뒤 경쟁기관의 보유 판정을 보관 장비가 아닌 설치된 상위 기능으로 명확히 했다. 최신 엔진으로 대표 1시드 × 6전략(144계절·9,666검사)을 재실행했으며 해당 시드의 플레이어 요약과 경쟁기관 상태가 기존 결과와 모두 일치했다. 로컬 원자료는 `.preview/advanced-balance-review.json`, 최신 대표 비교는 `.preview/advanced-balance-latest-one.json`, 재현 스크립트는 `.preview/review-advanced-balance.mjs`다.
