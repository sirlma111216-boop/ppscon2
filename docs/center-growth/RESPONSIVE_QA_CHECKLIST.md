## 실제 동작 확인

- 시간→클래스 및 클래스→시간 모두 편성되고 완료 후 선택을 해제했다. 대관 검토 복귀 시 편성을 보존했다.

- 설치가 끝난 공예 도구+가마는 공예실에서만 전문 도예를 열었다. 실제 마지막 주 오전 전문 도예12명·저녁 공예9명 기록을 UI에서 확인했다. 오후는 실제 운영 기록이 없어 빈 시간으로 표시됐다.
- 자동 시간대 재생이 끝난 뒤 마지막 실제 공예 장면이 유지됐고 결산창은 자동으로 열리지 않았다. ‘계절 결과 보기’로 열고 닫으면 장면이 유지됐다. 새로고침 후 공예실에 들어가도 실제 기록을 재생했다.
- 결과 시간표의 일요일 빈칸 선택 시 canvas0, 전문 도예 오전 선택 시 canvas1, 관람 팝업0을 확인했다. 외관·다른 방은 정적이었다. 관람 중 가용예산394.5점은 변하지 않았다.
