# 구현 기록

갱신일: 2026-11-06. 패키지 버전 0.4.0. 개발 브랜치 `feat/center-growth-reboot`.

현재 구현과 남은 작업을 기록합니다. 공모전 제출 완성본, 외부 플레이테스트 또는 재미 검증 완료를 뜻하지 않습니다. 예전 3실·5년·10개 경쟁기관 기록은 현재 규칙이 아닙니다. 상세 규칙은 `SPACE_AND_RENTALS.md`와 실제 엔진을 기준으로 합니다.

## 현재 플레이 가능한 범위

- **6년·24계절 턴·312주**를 계산합니다. 우리 센터와 경쟁기관 9곳, 총 10개 기관이 운영됩니다.
- A 소강당 1, B 생활체육실, E 공예실, F 배움실로 시작합니다. C 대강당·D 소강당 2·G 프리미엄회의실은 시설 사업으로 개방합니다.
- 대관 검토 → 남은 시간의 클래스 편성 → 13주 운영·결산 흐름입니다. 빈 시간과 대관 전체 거절도 허용합니다.
- 대관을 승인할 때 기존 클래스가 있으면 명시적인 교체 확인을 받습니다. 취소/실패하면 기존 클래스가 유지되며, 승인된 다른 대관을 덮어쓰지 않습니다.
- 장비별 구매·설치·마모·정비·8점 이전을 구분합니다. 같은 물품을 서로 다른 방에 별도로 설치할 수 있습니다.
- 방의 용도와 클래스 종류를 매칭합니다. A/D는 다목적, B/C는 운동과 주민 모임, E는 공예, F는 공예·디지털, G는 디지털·주민 모임입니다. 면적과 모든 필수 설비 조건도 별도로 검사합니다.
- 용도에 맞는 잠긴 클래스는 그림 카드로 보이며, 선택 후 난이도·필수 설비·설치 대기·정비 필요를 확인합니다. 다른 방의 장비로 잠금을 풀 수 없습니다.
- 대관은 수입, 클래스는 명성 성장에 더 크게 기여합니다. 주민 수요·요금·준비 인력·소음·관리 상태가 실제 운영에 반영됩니다.
- 경쟁기관도 같은 구매·설치·방 용도·대관/클래스 규칙을 사용합니다. 투자 성향은 정해진 전략이며 모든 상황을 학습하는 AI는 아닙니다.

## 조달과 공간 성장

물품 화면은 공식 화면의 공통 구조를 참고한 나라장터 카탈로그입니다. 분류·검색·같은 기능 비교·설치 장소·납품요구서를 구분합니다. 목록의 각 물품에 연결 클래스와 추가 설비를 표시하고, 해당 방에 설치할 수 없으면 구매를 차단합니다. 조달청 로고와 정적 나르미·달이는 사용자가 제공한 자산입니다. 게임 표시를 유지하며 실제 거래 기능은 없습니다.

시설 사업은 공고 → 업체 3곳 비교 → 공사비/유지비 확보 → 계약 → **9/18/31주** 공사 → 개방 순서입니다. 완성도는 대관 가치와 연결됩니다. 공사·유지비와 품질을 비교하며, 돈만 누르면 즉시 열리는 방식이 아닙니다.

환경 개선은 **정원·쉼터 → 외관·광장**의 순차 사업입니다. 기본 사업 규모는 2,400점/6,000점이며 제안에 따라 실제 견적·기간·관리비가 달라집니다. 완료한 사업은 명성, 이용 경험, 대관 견적과 외관 성장 그림에 반영됩니다.

## 평가와 최종상

2·4·6년 차 겨울에는 최근 2년을 종합평가합니다. 1·3·5년 겨울은 운영 결산입니다.

| 평가 항목 | 비중 | 측정 내용 |
|---|---:|---|
| 명성 | 25% | 기간 내 계절말 명성 평균 |
| 재정 건전성 | 20% | 운영비 충당률·다음 고정비 지급 여력 |
| 주민 만족 | 30% | 실제 방문 만족도와 취소된 예약 |
| 공공서비스 | 25% | 공공서비스 신청 대비 실제 참여 |

화면은 엔진의 `EvaluationRecord`와 `EVALUATION_COMPONENTS` 값을 사용합니다. 총점·4개 막대·순위·상격·예산을 먼저 표시하고, 산식/계절 세부 내역은 접습니다.

1·2·3위에 대통령상·국무총리상·장관상을 표시합니다. 2·4년 차 결과는 다음 2년 기본 연간예산 900점에 +6/+4/+2%, 하위 3곳은 −2/−4/−6%를 적용합니다. 이전 인상률과 누적하지 않습니다. 마지막 6년 차에는 다음 지원연도가 없습니다.

**6년 차 평가상**은 최근 2년 결과입니다. **6년 종합 최종상**은 평가 평균 50% + 마지막 평가 50%입니다. 최종 경쟁표·순위·포상은 `getFinalStandings`, `getFinalRank`, `getAwardForRank`로 일치시켰습니다. 동점은 최종점수 → 최근 공공서비스 → 최근 주민 만족 → 기관 ID 순서입니다.

## 그림과 진행 연출

- 외관에서 이름표를 눌러 실내로 들어갑니다. 처음부터 모든 편성/설명 패널을 펼치지 않습니다.
- 외관 3단계, 실내 7장, 클래스 카드 7장, 경쟁센터 외관 9장과 안내판 스킨 2종을 연결했습니다. 메인 화면은 생성 그림과 HTML 조작을 조합하며 평면도를 사용하지 않습니다.
- 우리 센터 비교 화면의 외관은 실제 환경 개선 완료 단계와 같습니다. 경쟁센터는 각각 다른 건물 그림을 보여줍니다.
- 1280×720 같은 낮은 데스크톱에서 외관 높이를 제한하고, 모바일 이름표는 그림 안에서 겹치지 않도록 배치했습니다. 최종 실제 브라우저 검증은 별도 통합 QA 기록을 따릅니다.
- 클래스 잠금·비활성화가 그림 자체를 흐리게 만들지 않도록 채도/투명도 필터를 제거했습니다.
- 본게임 센터 장면에는 사람 애니메이션이 없습니다. 정적 대화 초상 3장과 정적 클래스 그림의 사람은 유지합니다.
- 운영 장면은 **13주차·마지막 주 결과** 5칸 요약입니다. 결과 상태와 같은 시점의 시설·공사 상태를 보여줍니다. 재생/건너뛰기는 경제 계산을 반복하지 않습니다.
- **도예 수업은 별도 미리보기, 본게임 미적용**입니다. 해당 시안의 진행 상태를 본게임 완성도로 집계하지 않습니다.
- 도예 미리보기는 한 장의 불변 그림과 인물 내부의 작은 동작으로 수정했습니다. 실제 재생용 그림 80,006바이트 + 움직임 코드 2,698바이트이며, 저장용 120프레임 무손실 WebP는 2,471,942바이트입니다. 저장용 파일은 재생 화면에서 요청하지 않습니다. 고정 영역 픽셀 차이 0 및 반복 경계 검증은 `POTTERY_ANIMATION_PROTOTYPE.md`를 따릅니다.
- 음향은 Web Audio 합성 BGM/선택·구매·실행·결과 효과음 스케치입니다. 최종 제작 음원이나 검청 완료로 표시하지 않습니다.

## 저장과 호환

저장키 `ppscon2.center.v1`을 유지합니다. 이전 버전, 경쟁기관 수 변경, 평가 스키마 변경 전에는 원본 JSON을 backup 키로 보관합니다. 마이그레이션은 자금·장비·대관·공사·기존 보고서를 보존합니다.

기존 경쟁기관 10곳 저장에서는 온누리만 제외하고 9곳을 유지합니다. 과거 보고서는 당시 참가 기관 수를 기록하여 11위/10곳 같은 모순을 피합니다. 이전 점수를 새 평가 지표로 소급 재계산하지 않으며, 새 지표가 일부 계절만 측정됐으면 `partial`과 측정 계절 수를 표시합니다.

개발 중 HMR로 React 상태만 이전 스키마를 가진 경우에도 렌더 계산 전 `migrateSave`로 정규화하고 한 번 state에 반영합니다. 완료한 계절을 다시 실행하지 않습니다.

1. **재미와 밸런스:** 외부 플레이테스트, 서로 다른 투자 전략의 장기 검증, 후반 여유자금과 평가 난이도 조정.

4. **조달 소재:** 혁신제품 시범사용·관찰·반납, 전체 생애주기비용 모형은 미구현입니다. 현재는 구매·유지·설치·사업 품질의 선택입니다.
5. **최종 아트/사운드:** 새 그림의 시각 일관성, 조달 장비의 추가 원화, 평가/엔딩 전용 원화, 완성 음원과 믹싱.
6. **접근성/배포:** 실제 기기 터치·키보드·읽기 순서, 독립적인 신규 E2E, 공개 배포 검증. 자동생성 PNG 원본과 실제 사용 WebP의 배포 범위도 점검합니다.
