## 수업과 조달

일반 클래스 7종을 유지하고 전용 11종을 더했다. 대관 3종 포함 활동 21종, 물품안 23종이다. 방별 총 클래스는 A7/B6/C7/D7/E5/F5/G5다.

| 방 | 전용 수업 |
|---|---|
| B 생활체육실 | 기구 필라테스·실내 사이클 |
| C 대강당 | 뮤지컬·주민 오케스트라·무대기술 |
| E 공예실 | 전문 도예·생활 목공 |
| F 배움실 | 주민 영상 제작 |
| G 프리미엄회의실 | 스피치·발표·외국어 토론·창업 피칭 |

전용 수업은 지정 방과 그 방의 필수 장비를 모두 검사한다. 다목적실도 우회할 수 없다. 종류별 센터 전체 주2회 한도, 유한 수요, 운영비·관리 상태를 사용한다. 필라테스는 수익, 전문 도예는 명성, 영상 제작은 균형형이다. P06 생활안전은 무료 공공교육이고 모임 대관 P05와 구분한다.

나라장터를 소재로 한 카탈로그에 분류·검색·가격/유지비 비교·설치 장소·연결 수업·추가 설비·납품요구를 표시한다. 사용자 제공 공식 로고와 정적 마스코트를 사용한다. 실제 거래 기능은 없다.

활동 장비는 C 3자리, 나머지 방2자리이며 설치 대기도 포함한다. flex/quiet는 보조, energy/guide는 센터 공용으로 별도다. 보관·이전·재설치는 각각8점이다. 보관해도 개체·마모·유지비를 유지하고 재설치는 준비 시간을 사용한다. 영향을 받는 클래스는 명시적 확인 후 비우며 승인 대관을 자동 취소하지 않는다. 매각은 미구현이다.

시설은 공고→3업체 비교→계약→9/18/31주(1/2/3턴) 공사→개방이다. 비용·완성도·관리비·대관 가치가 다르고 예상 완공 계절·주차를 표시한다. 조경2400·외관4000·광장2000점 규모의 환경 사업은 순서 없이 독립 계약하며 완료 조합8종으로 외관이 바뀐다. 구형 외관·광장 복합계약은 비용·진행·효과를 보존하고 중복 구매를 막는다.

## 운영 장면

- 공예 P01/P02 및 전문 도예 P12의 현재 방·현재 시간에 실제 참여 기록이 있을 때 방 그림 자리에 테두리 없는 인라인 장면을 표시한다. 계획·외관·다른 수업·참여0·빈 시간은 정적이다.
- 600×400 WebP 원화80,006바이트와 별도 모션 코드로 4.8초를 반복한다. 프레임120장을 다운로드하지 않는다. 건물·가구·환경을 고정하고 네 인물의 고개·상체·팔을 연동한다. 작은2D 변형이며 실제 영상이나 새로운 포즈 생성은 아니다.
- 자동 시간대 재생 후 마지막 실제 공예 시간으로 이동해 계속 보여준다. 사용자가 ‘계절 결과 보기’를 눌러야 결산창을 연다. 재접속 결과 상태에서도 실제 기록을 볼 수 있다.
- 결과 시간표는 편성이 아닌 관람 시간만 변경한다. 수동으로 빈 시간을 고르면 정적 방을 보여준다. 동작 정지와 시간대 재생 정지는 독립적이며 돈·참여·공사를 다시 계산하지 않는다.
- 다른 클래스 애니메이션, 무대 공연 영상은 미구현이다.

## 평가와 저장

2·4·6년 겨울의 종합평가는 명성25%·재정20%·주민 만족30%·공공서비스25%다. 1·3·5년은 일반 결산이다. 상위3곳은 대통령상·국무총리상·장관상 및 다음2년 기본900점 예산에 +6/+4/+2%, 하위3곳은 −2/−4/−6%를 적용한다. 증감률은 누적하지 않는다. 6년 최종상은 평가평균50%+마지막평가50%이며 최근2년 평가상과 구분한다.

전용 규칙 이관 전에 브라우저 저장 원문을 백업하고 재읽어 검증한다. 다른 원문의 기존 백업도 보존한다. 백업 실패 시 기존 주 저장을 덮어쓰지 않는다. 새 규칙과 맞지 않는 옛 전용 편성만 비우고 해당 장비는 무료 보관한다. 기존 일반 수업·승인 대관에 필요한 장비는 보존한다. 자금·진행·개체·마모·과거 운영 기록을 유지하며 이관 내역은 도움말에서 확인 후 지운다.

복원이 불가능한 최신 형식의 손상 저장·잘못된 JSON·빈 문자열도 새 게임 저장 전에 원문을 별도 백업한다. 백업 실패 시 기존 저장을 유지하는 회귀 검사8개를 통과했다.
