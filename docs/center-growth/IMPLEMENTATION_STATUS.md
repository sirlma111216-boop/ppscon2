# 첫 플레이 구현 기록

작성일: 2026-11-05. 버전 0.3.0. 브랜치 `feat/center-growth-reboot`.

이 문서는 실제 구현과 기획 초안의 차이를 기록합니다. 공모전 제출본 또는 재미 검증 완료를 뜻하지 않습니다.

## 현재 플레이 가능한 범위

- 물품 구매, 3개 방의 개방·용도 선택, 주간 5칸 편성, 13주 운영, 계절 결산, 연말 평가, 5년 최종 평가를 연결했습니다.
- 매주 수요를 배정하고 수입·지출·장비 마모·신뢰·경험·숙련을 계산합니다. 모든 칸을 채우지 않아도 진행합니다. 예산 유보금은 필수 운영을 보호합니다.
- 활동 10종, 물품안 12종. 장비 기능, 구매비, 설치 칸, 유지비, 마모, 소음과 준비 부담이 선택에 영향을 줍니다.
- 방별 장비를 8점에 이전할 수 있습니다. 대상 방의 자리·용도·예산을 검사하고 첫 주 설치 한 칸을 사용합니다. 원래 방의 편성은 유지하며 실행 불가능한 활동을 표시합니다.
- 성향이 다른 경쟁기관 10곳이 실제 구매와 운영을 합니다. 순위, 최근 투자, 대표 활동, 신뢰, 공간과 장비 수를 볼 수 있습니다.
- 첫 주 준비 연출 후 실제 계산된 **2주차**의 5개 시간대를 대표 장면으로 보여줍니다. 이용자가 없거나 활동이 실패하면 주민을 채워 넣지 않습니다. 정산은 애니메이션과 별도로 한 번만 수행합니다.
- 새 배경 1장과 오지선·한도윤·윤하린 초상 3장. 별도 SVG 주민·물품과 동작 애니메이션을 사용합니다. 사용자 입력에 따라 인물과 짧은 대화가 바뀝니다.
- 자동 저장·복원, 클릭/드래그 편성, 키보드 모달 조작, 움직임 줄이기, 모바일 레이아웃, 음악 켜기/끄기를 구현했습니다.
- 배경음악과 선택·구매·실행·결과 효과음은 직접 작성한 Web Audio 합성 스케치입니다. 최종 제작 음원으로 교체할 예정입니다.

## 확인한 내용

- `npm run build`: 타입 검사와 Vite 프로덕션 빌드 성공.
- `npm test`: 51개 통과. **새 경영 엔진 15개**, 기존 게임 회귀 검사 36개입니다. 51개 모두가 새 게임 검사인 것은 아닙니다.
- 새 엔진 검사: 구매·유보금, 공간 제한, 이전, 설치·정비, 지원 계약, 수요 중복 배정 방지, 소음, 저장 데이터, 5년/260주, 경쟁기관 10곳, 중복 정산·추가 새해 지원금 방지.
- 실제 브라우저: 공예·매트 구매 → 유료·무료 활동 편성 → 준비/활동 연출 → 결과 → 경쟁기관별 최근 투자 → 다음 계절 → 새로고침 복원을 확인했습니다.
- 장비 이전으로 가용예산이 8점 줄고 대상 방에서 활동을 편성할 수 있는 것을 확인했습니다. 이전 후 운영도 진행했습니다.
- 첫해 겨울 평가와 2년차 진입을 확인했습니다. 현금 504.5점에서 새해 지원금 480점이 한 번 반영되어 984.5점이 됐고 필수 운영비 332점이 유보됐습니다.
- 390 × 844 모바일 화면에서 일정·버튼을 확인했습니다. DOM 문서 폭 375px로 390px 뷰포트의 가로 넘침이 없었습니다.
- 테스트 탭에서 기록된 브라우저 경고·오류 없음. 오디오는 재생 제어와 실행 오류를 확인했으며 최종 음질 검청은 남아 있습니다.
- 실제 화면은 로컬 `.preview/gameplay.png`, `.preview/annual-review.png`에 보관했습니다. 이 폴더는 Git에서 제외합니다.

## 다음 개발 우선순위

1. **재미와 난이도 검증:** 서로 다른 투자 전략으로 여러 회차를 직접 플레이하고, 무조건 이기는 편성·무료 활동 반복·가격 선택의 일방적 우위를 조정합니다. 아직 외부 플레이테스트는 하지 않았습니다.
2. **계절 중 사건과 개입:** 현재는 13주가 한 번에 계산됩니다. 인물 사건, 선택 결과, 임시 요청, 중간 정비·프로그램 조정을 넣어 실제 이야기 분기와 통제감을 강화합니다.
3. **성장 보상:** 공간 단계별 배경·설비 외형·활성 주민 수를 늘리고, 공공서비스 변화와 기관의 개성이 시각적으로 축적되게 만듭니다.
4. **조달 소재 심화:** 혁신제품 시범사용·관찰·설정 변경·반납, 생애주기비용 비교, 실제 공모전 취지와 표현의 최종 검토가 남았습니다. 현재 구매 화면은 게임용 단순 모형입니다.
5. **인물/이야기:** 나머지 주요 인물, 표정, 경쟁기관 담당자, 친밀도·관계·연말 사건·엔딩 변주를 제작합니다. 현재 대화는 짧은 상황 안내입니다.
6. **최종 아트/사운드:** 초상 표정 세트, 실제 활동 인물의 고급 스프라이트, 성장 단계별 배경, 연말·엔딩 원화, 완성 BGM/효과음/환경음과 믹싱을 제작합니다.
7. **접근성과 배포:** 화면 읽기 순서, 실제 휴대폰 터치, 시각 대비, 자산 로딩 최적화, 독립적인 신규 E2E 자동화와 배포 미리보기 검증을 진행합니다.

## 기획과 다른 간소화

- 20회 편성은 5년 × 4계절로 압축합니다. 매주 직접 새 계획을 입력하는 260턴 구조는 아닙니다.
- 경쟁기관은 동일한 계산을 쓰지만 장기 투자는 고정 성향별 순서입니다. 3계절마다 목표를 재평가하는 AI는 아직 없습니다.
- 준비 인력 우선순위는 A→B→C이며 개별 우선순위 편집은 없습니다. 요금 방식은 센터 공통입니다.
- 돈은 소수 둘째 자리까지 반올림한 게임 점수입니다. 기획의 정수 최소 화폐 단위 저장은 아직 적용하지 않았습니다.
- 큰 사건 분기, 혁신제품 시범사용, 계절 중 일시정지 선택은 없습니다. 장비 고장·비용 부족 등은 해당 활동을 쉬고 결과에서 알려 줍니다.

## 로컬과 공개 사이트

요청받은 `ppscon2` 폴더에 저장소를 복제하여 작업했습니다. 기존 `main`을 바꾸거나 GitHub 푸시·Cloudflare 배포를 실행하지 않았습니다. 로컬 폴더에서 `start-game.cmd`로 실행합니다. 새 게임 코드와 문서는 `src/center`, `public/center`, `docs/center-growth`를 기준으로 읽으세요.
