# 조달 화면 참고와 게임 적용

확인일: 2026-11-06. 실제 구매·계약 규정을 가르치는 업무 프로그램이 아니라, 문화체육센터 경영 게임에 공공조달의 역할과 선택 구조를 보여 주는 화면이다.

## 공식 자료에서 확인한 내용

| 공식 자료 | 확인 내용 | 이번 적용 |
| --- | --- | --- |
| [조달청 현재 홈페이지](https://www.pps.go.kr/kor/index.do) | 조달청의 정책·기관 소개와 나라장터 업무 서비스가 구분된다. 현재 관련 누리집에서 **나라장터 쇼핑몰**을 `shop.g2b.go.kr`로 연결한다. 물품구매와 시설공사도 별도 업무로 분류한다. | 조달청 원본 로고와 `나라장터 쇼핑몰 / 시설공사` 업무명을 구분. 두 화면의 기관·계정·현재 위치 표시를 통일. |
| [조달청 물품구매 개요](https://www.pps.go.kr/kor/content.do?key=00176) | 계약 방식별 공급 구조와 수요기관의 납품요구를 설명한다. | `조달청 → 계약 마련 / 센터 → 상품 선택 / 공급업체 → 납품·설치`로 역할을 짧게 구분. |
| [조달청 다수공급자계약 개요](https://www.pps.go.kr/kor/content.do?key=00181) | 비슷한 기능의 물품을 여러 공급자와 계약하여 공공기관의 선택을 지원하는 구조를 설명한다. | 같은 기능 상품의 구매비·유지비 비교를 보존하고 카탈로그에 구성·단가·설치 조건을 함께 표시. |
| [조달청 디지털서비스 수요기관 매뉴얼, 2025](https://digitalmall.g2b.go.kr/static/dmall/gov/pps/dm/pdf/guide/userManualInst_2025.pdf) | 상품 상세에서 제안요청, 요청 목록, 업체 제안서 확인, 결과 확인, 물품구매·납품요구로 이어지는 화면 구조를 확인할 수 있다. 디지털서비스 업무 매뉴얼이므로 시설공사의 실제 절차와 동일하다고 취급하지 않는다. | 목록 → 선택 내용 → 요구서라는 정보 계층, 현재 위치와 문서 제목, 단계별 진행 상태를 공통 디자인에 반영. |
| [조달청 디지털서비스 쇼핑가이드](https://digitalmall.g2b.go.kr/coGuide/dmall/CoGuideCSMas001.html) | 조달업체와 수요기관의 사용자 안내를 별도로 제공한다. | 두 게임 화면에 `수요기관 · 늘봄 문화체육센터`를 표시하여 플레이어의 입장을 분명히 함. |
| [조달청 시설공사 낙찰자 결정제도](https://www.pps.go.kr/kor/content.do?key=00007) | 공사 계약에는 가격 외 수행 능력 등을 고려하는 여러 선정 방식이 있다. | 게임의 비용·기간·완성도 비교를 유지. 이를 실제 낙찰 공식 또는 자유로운 업체 선택 절차의 재현이라고 설명하지 않음. |

나라장터와 쇼핑몰 본 서비스는 이번 웹 도구에서 SSO 이동 때문에 본문을 읽지 못했다. 따라서 위 공식 홈페이지·업무 안내·공개 매뉴얼로 확인한 구조를 재구성했다. **2026년 로그인 후 화면의 색상·배치를 그대로 복제했다고 주장하지 않는다.** 2022년 이전 종합쇼핑몰 예시나 비공식 블로그를 최신 화면의 근거로 사용하지 않았다.

## 기존 화면과 변경점

| 항목 | 기존 | 변경 |
| --- | --- | --- |
| 기관 표시 | 상자 아이콘과 자체 제작 워드마크 | 사용자가 제공한 조달청 가로형 로고, 원본 색상·비율 유지 |
| 두 조달 업무 | 물품·시설 헤더 디자인이 별개 | 공통 `ProcurementHeader`로 기관, 게임 배지, 수요기관, 업무 위치 통일 |
| 안내 캐릭터 | 없음 | 나르미·다리 원본 PNG와 한 문장 메모. 이동·사람 애니메이션 없음 |
| 물품 탐색 | 카탈로그 제목 옆 작은 검색창 | 목록 상단의 큰 상품명·기능 검색, 상품 분류, 검색 건수, 설치 대상 표시 |
| 상품 목록 | 설명 문장 비중이 큼 | 그림, 물품번호, 짧은 구성, 단가·유지비·설치 시간 중심 |
| 주문 | 조달 요청서, 조달 요청 보내기 | **납품요구서, 납품요구 보내기**. 실제 클릭 결과와 예산 계산은 동일 |
| 시설 공고 | 큰 공간 소개와 3개 업체 카드 | 공사명·게임 공고번호·수요기관·장소를 짧은 문서 표로 제시. 제안서의 비교 항목 정렬 강화 |
| 진행 단계 | 물품 요청/시설 공사의 별도 스타일 | 상품 조회→비교·납품요구→납품·설치 / 입찰공고→제안서 비교→계약·시공→완료·개방 |

## 적용 범위

- 가격, 유지비, 예산 확보, 구매 가능 조건, 시설 공고·업체 선정·시공 계산은 변경하지 않았다.
- 실제 인증·로그인·계약 송신 기능을 추가하지 않았다. `게임 속 조달 화면`과 기존 게임용 거래 안내를 유지한다.
- 독립적인 검사·검수 의사결정은 아직 게임에 없다. 따라서 UI에 별도의 완료 단계나 실제 검사서를 만들지 않았다. 현재 물품의 설치 완료 판정과 시설 완공 판정을 그대로 사용한다.
- `pps-logo-horizontal.jpg`와 `nareumi-dari-3d.png`는 사용자 제공 공모전 자산이다. 원본 파일을 바꾸지 않고 `height: auto` 및 `object-fit: contain`으로 표시한다. 세로형 로고는 가로형과 중복되지 않도록 이번 헤더에 사용하지 않았다.
- 모바일은 분류를 가로 스크롤하고, 검색·목록·납품요구서 순으로 읽는다. 로고와 게임 배지는 숨기지 않는다.
