# 도예 수업 — 고정 배경 움직임 시안

2026-11-06. 독립 미리보기에서 시작한 도예 장면이다. 최신 사용자 요청은 실제 운영 중인 공예 수업을 해당 방의 그림 자리에 보여 주는 방식이며, 팝업이나 계획 단계 미리보기는 제거한다. 아래에서 현재 사람 전체 동작의 검증과 이전 저장 시안의 기록을 구분한다. 본게임 화면 연결의 검증은 `IMPLEMENTATION_STATUS.md`에 별도로 기록한다.

## 변경 이유와 구현

앞선 8개 장면은 프레임마다 창문·선반·탁자까지 조금씩 달라져 화면이 흔들렸다. 현재는 기존 첫 장면 `poster.webp` 한 장을 불변 원본으로 사용한다. 네 사람의 실루엣을 각각 추적하고, 몸통의 기울기·호흡에 목 중심 고개 움직임과 어깨·팔꿈치의 팔 동작이 이어지도록 같은 사람 안에서 위상을 공유한다. 다른 프레임으로 배경을 교체하거나 카메라를 이동·확대하지 않는다.

이는 서로 다른 자세를 새로 그린 영상이 아니라 **한 그림에 작은 관절 동작을 주는 시안**이다. 몸통 기울기는 약 0.5~0.75도, 목 중심 고개 움직임은 약 1.4~1.8도 범위다. 큰 자세 변경, 가려진 신체의 새 노출, 입 모양이나 손가락 관절의 독립 연기는 표현하지 않는다. 배경을 복원할 새 그림이 없으므로 실루엣 가장자리는 점차 움직임을 줄여 고정한다. 완전한 뼈대 애니메이션이나 새 프레임 영상과 같은 자연스러움을 보장하지 않는다.

- 성인 수강생 3명 + 강사 1명, 600 × 400.
- 반복 주기 4.8초. 네 사람의 시작 위상을 다르게 하고, 같은 사람의 몸·고개·팔은 약간의 시간차를 두고 연결한다.
- 브라우저: Canvas와 `requestAnimationFrame`으로 연속 계산. 실제 화면 주사율과 기기 성능에 따라 표시 프레임률은 달라진다.
- 저장 파일: `pottery-fixed.webp`, 120프레임, 25fps, 무한 반복, 무손실 압축, 약 2.47MB. 손 동작 보강 전의 보관본이며 최신 런타임에서 사용하지 않는다. GIF와 같은 반복 이미지이며 파일 형식은 animated WebP다.
- 일시 정지 시 그 순간에 멈추고 재생 시 이어진다. 탭을 벗어나면 중지하며, 동작 줄이기 설정은 자동재생을 끈다.
- 미리보기: `/center/prototypes/pottery/index.html`.

## 손 동작 보강 전 저장 시안의 확인 결과

아래는 손 동작 보강 전에 `node scripts/export-pottery-motion.mjs`로 생성·검사한 저장 시안의 결과다. `pottery-fixed.webp`와 `motion-validation.json`을 최신 보강본으로 다시 생성한 결과는 아니다.

- 240,000픽셀 중 동작 영역 28,411픽셀, 고정 영역 211,589픽셀.
- 고정 영역은 120프레임 모두 채널 차이 **0**.
- 0초와 4.8초 계산 결과 완전 일치.
- 마지막→첫 프레임 차이 0.2101/채널로 일반 프레임 간 최대 차이 0.2153보다 작음.
- 인코딩한 120프레임을 다시 디코딩해 원본 계산 결과와 모두 일치 확인.
- 상세 수치: `public/center/prototypes/pottery/motion-validation.json`.

## 이전 손 동작 보강 기록

2026-11-06, 손 움직임이 약하다는 피드백에 따라 손의 진폭만 5.0~6.2px로 늘렸다. `src/center/potteryMotion.ts`와 독립 시안의 `motion.mjs`를 함께 변경했으며 배경·카메라·몸의 미세 동작·4.8초 주기와 28,411픽셀 마스크는 유지했다.

실제 `poster.webp`에서 0ms 프레임과 비교한 결과다. RGB 채널 차이는 움직임 변화량이지 자연스러움이나 사용자가 느끼는 품질 점수는 아니다.

| 비교 시점 | 최대 채널 차이: 이전 → 보강 | 평균 채널 차이: 이전 → 보강 | 마스크 밖 변경 픽셀 |
|---|---:|---:|---:|
| 600ms | 82 → 154 | 0.243154 → 0.385356 | 0 |
| 1200ms | 118 → 190 | 0.276193 → 0.414071 | 0 |

당시에는 기존·보강 마스크의 픽셀 일치를 확인했다. 이후 사용자가 손만 움직이는 부자연스러움을 지적해 아래 사람 전체 동작으로 교체했다. 이 표의 수치는 현재 동작의 결과가 아니다. 손만 보강한 코드 보관본은 `.preview/pottery-motion-hand-only.mjs`다.

## 현재 사람 전체 동작과 검증

사람별 실루엣 안에 머리·몸통·양팔을 포함하고 세 개의 도자기는 고정 물체로 따로 제외했다. 경계 1픽셀은 고정하고 안쪽 4픽셀 구간에서 움직임을 부드럽게 줄인다. 역방향 샘플링의 네 이웃 픽셀도 같은 사람에 속할 때만 사용하므로 탁자·그릇·다른 사람의 색을 끌어오지 않는다. 손만 5~6픽셀 움직이던 증폭은 없앴다.

실제 원본 그림을 40ms 간격으로 120번 렌더링하여 확인했다.

- 동작 마스크 58,489픽셀, 고정 영역 181,511픽셀. 손 동작 전용 마스크와는 다르다.
- 120프레임 모두 마스크 밖 채널 변화 0. 천장·창문·선반·탁자·바닥·세 도자기의 대표 영역을 별도로 검사했다.
- 0ms와 4,800ms 프레임은 완전히 일치한다.
- 마지막→첫 프레임의 평균 채널 차이 0.187928, 일반 연속 프레임 최대 차이 0.209375. 반복 경계에서 더 큰 점프가 생기지 않았다.
- 네 사람 각각의 머리·몸통·팔, 총 12곳에서 실제 픽셀 변화가 확인됐다.
- `tests/center/pottery-motion.test.ts` 8개 통과. 입력·기존 출력 불변, 알파 보존, 반복 경계, 고정 환경, 신체 부위별 움직임, 본게임/독립 모듈의 픽셀 일치를 포함한다.
- `npm run check` 통과. 한 로컬 Node 실행에서 60프레임 평균 렌더 계산은 약 10.9ms였으며 브라우저·모바일 프레임률을 보장하는 수치는 아니다.

현재 측정은 `.preview/pottery-coherent-metrics.json`, 재현 스크립트는 `.preview/measure-pottery-coherent.mjs`, 마스크 시각화는 `.preview/pottery-person-mask.png`에 있다. `.preview/pottery-coherent-contactsheet.png`는 왼쪽 위부터 0/1.2/2.4/3.6초 비교다. `.preview` 자료는 로컬 검증용이며 배포 자산이 아니다. 픽셀 차이는 움직임의 존재와 고정 영역을 확인하며, 자연스러움의 판정은 실제 재생 확인이 필요하다.

## 출처와 재현

기초 그림은 이 대화에서 built-in ImageGen으로 제작한 다인 도예 수업 장면의 첫 프레임이다. 생성 원본은 `.preview/art-originals/pottery/pottery-group-sprites.png`에 보관한다. 기존 8프레임 시안도 같은 보관 폴더에 남기며 배포 화면에서는 사용하지 않는다. 이번 고정 배경 수정에는 새로운 이미지 생성이나 외부 영상 API를 사용하지 않았다.

- 실제 움직임 정의: `public/center/prototypes/pottery/motion.mjs`
- 재현/검증: `scripts/export-pottery-motion.mjs`
- 플레이 화면: `public/center/prototypes/pottery/index.html`

본게임 연결은 같은 알고리즘을 타입과 함께 옮긴 `src/center/potteryMotion.ts`를 분할 번들로 불러온다. `PotteryActivity.tsx`는 위 `poster.webp` 한 장을 재사용한다. public의 `motion.mjs` 직접 import는 개발 서버에서 차단될 수 있어 본게임 연결에서는 사용하지 않으며, 독립 미리보기와 원래 검증 재현 파일로 보존한다.

최신 통합 대상은 실제 운영 중인 현재 방·시간의 공예 수업이며 모든 클래스로 확대 적용한 것은 아니다. 본게임의 건물 외관에는 사람 애니메이션을 넣지 않는다. 화면의 재생·정지·장면 변경은 운영 계산을 다시 실행하거나 자금·참가 인원·공사 진행을 바꾸지 않는다.
