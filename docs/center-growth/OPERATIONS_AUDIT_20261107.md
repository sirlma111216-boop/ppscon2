## 카드 표시
정상 예측이 가능하면 현재 편성의 13주 평균을 표시한다. 운영 예상이 전혀 없거나 장비가 잠겨 있으면 정상 운영·정원 70% 가정의 수입/비용/차익/명성을 표시한다. 실제 무료 강좌의 수입과 직접 명성은 규칙대로 0이며 공공서비스 기여를 별도 표시한다. 만족도 숫자는 표시하지 않는다.

카드 경고는 한 줄 원인만 표시한다. 예: 다른 수업에 배정 / 시간대 수요 없음 / 수강료 초과 / 운영비 부족. 상세는 사용자가 펼칠 때만 보여준다.
