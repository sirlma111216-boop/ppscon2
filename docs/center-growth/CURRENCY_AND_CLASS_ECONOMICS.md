# 원화 표시와 클래스 예상 효과 (2026-11-07)

현금은 원, 종합평가 점수는 점으로 구분한다. 기존 회계 단위 1 = 10,000원. 내부 단위와 저장 포맷, 수요, 수강료 비율, 보조금, 경쟁기관 로직은 유지했다. 이는 표시 스케일 전환이며 모든 항목을 실제 견적에 맞춰 개별 재산정한 것은 아니다.

공공 강좌는 보조금과 운영시간에 따라 수강료 차이가 크다. 본 게임의 운영비는 수업 직접비, 공익 수업은 지원 후 센터 부담액이다. 연간 예산은 전체 기관 급여·토지·건축비가 아니라 플레이어가 쓰는 추가 운영 재원이다. 실제 공공기관 견적이나 예산 산정 자료로 사용하지 않는다.

## 게임 표시 예시
|항목|원화 표시|
|---|---:|
|기본 공예 장비|900,000원|
|체육 매트 세트|600,000원|
|기본 음향 세트|1,200,000원|
|리포머 세트|7,200,000원|

장비 세트는 공동 사용하는 게임용 구성이다. 위 공개 제품 가격은 참고 비교값이며 해당 게임 세트의 실제 공급 견적을 뜻하지 않는다.

## 클래스 카드와 상세
카드에는 주 1회 평균 수입, 직접 운영비, 수업차익, 명성 기여를 표시한다. 사용자 후속 요청에 따라 만족도 예상치와 개별 증감 수치는 숨긴다. 평가회에서만 평가 기간의 센터 전체 주민 만족 점수를 공개한다.

개설 가능 수업은 현재 수요·장비·다른 편성에 해당 수업을 놓은 복사 상태로 13주를 계산한다. 계산은 실제 운영 엔진을 사용하며 사용자 상태와 저장 데이터를 변경하지 않는다. 명성 기여는 계절 상승 한도 적용 전 값이다. 고정비·장비 유지비·계절 이벤트는 수업 직접비와 별도다.

잠긴 수업 등은 정원 70%, 관리 90, 장비 정상, 소음 없음의 개설 후 가정이며 카드에 가정임을 명시한다. 상세에는 참여 예상, 1인 수강료, 비용·효과와 전제를 표시한다. 실제 운영 결과를 보장하는 수치가 아니다.
