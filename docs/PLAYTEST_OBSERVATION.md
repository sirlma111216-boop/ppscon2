# 첫 임무 관찰표 — 비개발자 5명

**아직 아무에게도 시험하지 않았다.** 이 표는 실제 사람 5명에게 임무 1을 맡길 때 쓰는 기록지다.
결과를 채우기 전에는 어디에도 ‘사용자 테스트 완료’라고 적지 않는다.

## 진행 방법

- 설명 없이 주소만 열어 준다. “끝났다고 생각될 때까지 해 보세요”라고만 말한다.
- 막혀도 30초는 지켜본다. 도움을 줬다면 무엇을 알려 줬는지 적는다.
- 임무 1의 결과 화면이 나오면 멈추고 아래 두 질문을 한다. 더 하고 싶어 하면 임무 2까지 지켜본다.
- 이름·연락처는 적지 않는다. 구분은 A~E로 한다.
